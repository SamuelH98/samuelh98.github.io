# Background music

Drop the instrumental (no vocals) track here as **`theme.mp3`**.

- The site loads `public/audio/theme.mp3`, loops it, fades it in to 50% volume, and shows a
  "Sound on/off" button (bottom-left) once the file loads. If the file is missing the button stays hidden.
- Browsers block autoplay until the visitor interacts, so playback starts on the first click/tap/keypress.
- Only use audio you have the rights to. To make an instrumental from a track you own, use a
  stem-separation tool (for example Demucs or Ultimate Vocal Remover) and export the "no vocals" stem.
